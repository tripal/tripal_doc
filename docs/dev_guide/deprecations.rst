
Deprecations in Tripal 4.x
==========================

Several of Tripal 4.x's functions have been modified, deprecating their older versions. While it is ok to use that code at the moment, legacy code may/will disappear in future releases. Before Tripal 4.x developers reuse code of the deprecated legacy functions, they need to be aware of the deprecated status of the function. This section gives a list of deprecations in Tripal 4.x and provide alternate functions to use in their place.
